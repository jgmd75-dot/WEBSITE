Install

Download

Get the ZIP from the button above (or clone the repository) and unpack it.

Copy into REAPER

In REAPER choose Options › Show REAPER resource path. Copy every .jsfx and .jsfx-inc file into the Effects folder there — a subfolder such as Effects/GFX is fine, as long as all the files sit together.

Find them

Open the FX browser, press F5 to rescan, and search for GFX. Instruments go on a track and play from MIDI; effects go on any track, bus or the master.

Optional extras

For MIDI export from G Deep 16 and G PCM 12, load the scripts in Scripts/ with Actions › Load ReaScript. G Pulse reads pattern files from Data/gfx-drum-patterns (copy that folder into REAPER's Data folder).

The .jsfx-inc files are shared parts (the panel look, the output stage and so on). The plug-ins need them in the same folder.
